Аудит: принципы этого экрана

  1. 1
    Имя всегда видноКолонка сотрудника закреплена при горизонтальной прокрутке, часы за неделю - рядом: перегруз виден без открытия карточки.
  2. 2
    Одна главная кнопкаНа экране один primary - «Опубликовать». Остальные действия вторичные, чтобы взгляд не прыгал.
  3. 3
    Цвет = смысл, не украшениеЦвет смены только по роли (4 оттенка), красный - только ошибки. Никаких «просто красивых» цветов.
  4. 4
    Покрытие под сеткойСтрока «нужно / стоит» по каждому дню: менеджер видит дыры до публикации, а не в смену.
  5. 5
    Состояния читаются без легендыОтпуск - штриховка, конфликт - красная плашка с «!», пустая ячейка - «+» по наведению.
  6. 6
    Плотность - настройка, а не компромисс«Компактно» для планирования 30+ человек, «Свободно» для планшета у шефа.
